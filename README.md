# AI Workspace

这是一个个人 AI 工作区仓库，用于集中管理、积累和维护各类 AI Agent 的**指令规范（Instructions）**、**提示词模板（Prompts）**以及**技能扩展（Skills）**。

---

## 目录结构

```text
ai-workspace\
  └── instructions\             # AI 说明文档 (按作用命名)
```

---

## 文件说明

### instructions目录

这里记录 `instructions\` 目录下各说明文档的具体作用与使用场景：

**[`project-learning-dev-evolution.md`](./instructions/project-learning-dev-evolution.md)**

---

## 使用指南

**instructions**：

1. **选择指令文档**：在 `instructions\` 目录下选择符合当前任务需求的说明文档（如 `project-learning-dev-evolution.md`）。
2. **复制到目标项目**：将该文件复制或拖拽到目标项目的根目录（或对应的配置目录）。
3. **改名为对应平台的标准文件名**：参考将文件名修改为目标工具识别的标准规范文件名（如改名为 `AGENTS.md` 或 `CLAUDE.md`）
